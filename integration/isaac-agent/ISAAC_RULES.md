# 当前规则入口 / Current policy reference

当前规则以 [能力矩阵](docs/CAPABILITIES.md)、[架构与计划验证](docs/ARCHITECTURE.md) 和源码为准。 / Current rules are documented in the capability matrix, architecture and source.

- 即时战斗、蓄力、躲弹、地刺和爆炸撤离由本地执行。 / Combat, charging, dodging, spikes and bomb evacuation are local.
- DSH 只选择本地提供的有效候选并显式承担费用；未知信息不猜测。 / DSH selects valid local offers with explicit budgets; unknown remains unknown.
- 未识别药丸不预揭示、不自动使用。 / Unidentified pills are neither revealed nor automatically used.
- 献祭计数与费用已知时一次付款一次复核。 / A known sacrifice count/cost permits one payment before reassessment.
- 隐藏房开墙候选存在引擎元数据优势；不宣称纯视觉盲玩。 / Hidden-room offers have engine metadata advantages; no blind-vision claim.
- 只允许授权第 3 槽；无状态、房间、解锁或存档修改。 / Authorized slot 3 only; no state, room, unlock or save edits.

# v0.1.0 · 首个正式版 / First final release

**以撒 Repentance 原生 Windows 自动控制 + DSH 慢速策略插件，native130-dsh。**

**Native Windows automation for Repentance with a bounded DSH strategy agent.**

这是正式发布版本，非草稿、非预发布。该版本提供可运行的本地控制源码与已验证的插件接口。最近一次检查中，操作者新模型网关返回 `401 INVALID_API_KEY`；完整远端判断仍需恢复服务鉴权。此限制不影响显式选择纯本地模式。

This is a final release, not a draft or prerelease. It ships the working local controller source and verified plugin interfaces. At the last audit, the operator's migrated model gateway rejected its key with `401 INVALID_API_KEY`; remote inference requires restored authorization. Explicit local-only mode remains available.

## 功能 / Features

- 本地逐帧战斗、躲避、蓄力释放、地刺相位与炸弹撤离，Python 宏观路线控制。 / Local per-frame combat, dodging, charge/release, spike timing, bomb evacuation and Python macro routing.
- DSH 中单个 `gpt-6-luna` agent；四个受限工具，十二类策略子集，显式费用、上下文身份、期限、幂等与效果回执。 / One gpt-6-luna agent, four bounded tools, twelve strategic subsets, budgets, identity, deadlines, idempotency and effect receipts.
- `start` 观察模式；`arm` 开启本地+DSH；`arm-local` 纯本地；`pause` 等待实际正常暂停和稳定帧。 / Observation startup, explicit local+DSH or local-only arming, and acknowledged stable normal pause.
- 完整存档备份与哈希基线、授权第 3 槽检查、唯一进程归属和控制器断连暂停。 / Full save backup/baseline, authorized slot-3 checks, process ownership and disconnect pause.
- 原生运行时路径发现、首次安装、只读观察页及中英双语文档。 / Native runtime discovery, fresh deployment, read-only monitor and bilingual documentation.

## 已知限制 / Known limitations

- Agent 只承担可等待的意图选择。默认判断期限 45 秒，不参与毫秒级躲弹、地刺与充能释放。 / The agent handles deliberative intent only, with a default 45-second opportunity deadline; immediate control stays local.
- 主动/口袋槽 0 执行；复杂角色生命、未知药丸/费用和未登记机制保守拒绝。 / Execute active/pocket slot 0; reject unknown pills/costs/mechanics and unsupported character-health semantics.
- 稀有房间自然覆盖仍有限；未通过多种子多局 A/B 证明通关率提升。 / Rare-room live coverage is limited; no multi-run A/B benefit is established.
- 旧炸弹开墙候选使用相邻隐藏房的引擎元数据，存在信息优势。 / Legacy bomb-wall offers use privileged adjacent hidden-room metadata.
- 游戏侧使用普通输入回调、`EnableMods=0` 与 `--luadebug`；不要在 Mod 菜单额外启用 IsaacJev。 / Use native normal-input callbacks with EnableMods=0 and --luadebug; do not also enable IsaacJev in the Mod menu.

# 女A 参考声来源 / Voice references

Ten distinct anonymous female speaker IDs from the locally cached Common Voice zh-TW corpus. Dataset card: [OKHand/Clean_Common_Voice_Speech_24.0-TW](https://huggingface.co/datasets/OKHand/Clean_Common_Voice_Speech_24.0-TW). License: CC0-1.0.

十条参考声对应十位不同的匿名源说话人；精确逐字稿、原片名、原始音频哈希、参考声哈希和处理方式见 [references.json](references.json)。源数据没有年龄信息；“年轻、温柔、元气”等仅为角色选型方向。

## 2. 操作者入口

```powershell
python -X utf8 -B scripts/mc_runtime.py verify-source
python -X utf8 -B scripts/mc_runtime.py check-source --node 'C:\实际Node目录\node.exe' --output outputs/source-checks/run-001
```

`verify-source`核对当前检出或安装证明覆盖的实际文件，输出源码种类、数量、测试文件数及整体摘要。Git检出允许未提交源码，并如实绑定当前字节；安装目录必须与原整包来源完全对应。它不检查GPU、启动服务或生成原生准备证明。

`check-source`核对测试与夹具属于该来源，要求已有Windows x64 Node24.22.1及内置SQLite；同时检查game依赖声明、锁文件与已安装版本一致：ajv8.20.0、ajv-formats3.0.1、jpeg-js0.4.4、ws8.22.0。缺依赖或版本错误时直接返回原因，不自动下载或安装。完整应用安装仍负责提供全部依赖和许可，这个入口只消费已有环境。

检查以固定参数串行执行清单中的Node文件，设置60秒测试期限，关闭输入管道并去掉NODE_OPTIONS/NODE_PATH注入。输出必须是新的项目相对 `outputs/.../...` 目录，禁止写入state或替换旧证据。

目录保存 `inputs.json`、`test-output.tap` 和 `report.json`，绑定源码文件摘要、实际Node二进制摘要、依赖版本、命令与目录。测试失败保留原输出；摘要缺失、执行期源码改变、失败/跳过/取消/TODO均不算通过。夹具临时目录位于安装下outputs，运行器的日志与原生临时目录位于本次自检目录。

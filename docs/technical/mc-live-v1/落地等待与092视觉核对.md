本场15条任务在暂停前有1条仍运行；正常停止后只读复核为11条成功、4条取消，非终态为0。其中9条为核验导航，2条为木板、木棍制作，使用了091保留的1个橡木，完整的持续采集到工具生产链仍待验证。4条取消中，2条原因为死亡、1条遇险打断、1条为本次结束控制。

采到1次等待7个tick后落地READY的记录；该任务后来因死亡取消，逃生仍未成功。本轮采样可见的最大异常改路计数为1、总等待计数为7个tick。普通重生确认共3次，包含从上一轮保存的死亡界面恢复；本场实际采到2次新死亡，死亡前已有物品均完整保留。采样可能遗漏短暂中间状态，覆盖范围仍有限。

视觉请求4次成功、1次被模型队列抢占。成功结果中3次绑定了对应手持物采样，1次缺少对应采样而仅描述环境；4次成功描述都没有再称手持物为盾牌。3次成功绑定的采样至截图间隔分别为130、49和147毫秒。一般OCR、模组状态条含义和其他装备的识别准确率仍待验收。

正常停止后只读核对同场口播：6条有正式播放完成回执，另有10条丢弃、13条过期、1条失败。结束时已确认存活世界暂停，口播排空前后生命20→20、世界时间192282→192282；随后自有应用正常保存退出，原直播姬保留。本轮没有新录像、手机页面或性能基准。

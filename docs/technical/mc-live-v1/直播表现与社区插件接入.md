# MC直播表现修复与社区方案接入

分支mc；运行与实测设备为remote-3080，原生Windows。本文记录第084轮修复设计与源码接入边界；真实验证结果以本轮证据和[实现进度](实现进度.md)为准。既有120秒样本不能作为修复通过证据。

## 1. 需要纠正的直播表现

上一样本中，133.204秒观察期间没有任务效果通过核验，失败9次；角色在少数坐标之间往返。开场口播触及上下文预算，之后多次播报类似的采集失败。人物素材虽有动作，但随机选中的手部动作在圆形画面中不明显。

本轮以三个实际结果判断修复：背包或世界出现经游戏确认的任务成果；无人发弹幕时仍能围绕当前游玩产生简短、有变化的发言；圆形人物在不说话时仍有真实眨眼、偏头和肩颈变化。仅移动、生成文本或调度动作不算上述结果已经通过。

## 3. 自主游玩如何取得可见进展

仍由Agent与实际Mindcraft ItemWrapper依赖求解器的原生移植控制同一个NAIMEI。目标先拆解成当前缺失的材料、工作台和工具，再经过原生可行性检查提交任务。库存与世界变化依旧由游戏回执核验，不能把规划结果当作执行成果。

采集优先选择实际可见、够得到的来源；采矿落脚点必须容纳完整人物碰撞体。实际接近长时间无进展后，释放原输入，临时排除该来源60秒并重新选择，最多保留64个来源。失败签名按局部区域而非每个精确站位分组，避免几步位移就清掉失败记忆。已受控放置的工作台仍是需要重新确认的历史候选，背包工作台准备与真实放置链保留。

任务证明增加接近停滞次数、临时排除数、采矿站位和实际采矿耗时，便于区分未走到、未开始破坏、服务器未确认、未捡到掉落等情况。未验证的效果一律不播成成功。

084d实际已采到橡木原木并制作木板，但也暴露了历史工作台导航重复：走到旧位置后仍未观察到可用工作台，规划器却再次回到同一历史位置。现在仅对“返回已知/已观察工作台”的导航保留候选；任务结束后的新鲜观察仍未确认工作台时，取消该历史候选并准备便携工作台。普通探索和仍可用的真实工作台不受此失效处理影响。

## 4. 人格、自然语言与主动内容

configs/characters/female-a-mc-soul.md定义稳定性格、表达偏好和禁忌：知夏会做选择，会对眼前的小失误有反应，常用短句；偶尔停顿或自嘲，但不每句加口头禅，不把控制台和技术术语念给观众。SOUL附加于已发布人格，不能冒充替换身份或现实人生经历。

口播只携带当前角色、生命、饥饿、近处威胁与粗略时段；库存通过只读工具查询。路径网格、槽位和长账本仍由执行器与后台保存。任务来源保留固定失败含义与有界的真实部分效果证据；这使自然表达和事实核对能够同时成立。

同类失败有30秒话题间隔；已经播过的最近三条正式口播用于防重复。安静18秒后开始评估主动发言，32秒仍安静则提出一条围绕当前任务和真实观察的候选。已有请求或候选时不额外塞队。该行为明确标注为主播自主节目内容，不属于B站弹幕。

084d成片审阅发现，仅靠“避免重复”的提示仍会把多次导航成功说成类似的找木头、补工具计划。现在将没有关联观众请求的普通导航成功记为中间步骤，保留后台记录但不单独生成口播、不累计成功情绪；真实采集、制作、危险、失败及观众关联结果继续进入解说。口播方向同时要求说明具体成果，避免每句都追加同一个下一步计划。

真实联调还发现导航结果不带物品编号时，新增话题签名包含undefined，触发严格JSON序列化拒绝并使游戏连接保护性暂停。已将缺省字段明确编码为null，并增加真实task_update通道的失败结果回归；保留原失败记录，不能用此前327项通过掩盖该实机回归。

主动发言只是节目节奏候选，不保证一定播出；来源过期、世界切换、权限或播放状态变化仍由原队列拒绝。所有模型用途继续共享一个ModelQueue，所有声音继续使用唯一正式播放权及其完成回执。

## 5. 待机动作与情绪联动

保留原48动作和两个待机片段，继续使用相同的身体、面部、latent与mask帧号。待机自动模式优先选择圆形裁切内可见的偏头、点头、肩颈放松、坐姿变化，并周期选择已检查含真实眨眼的m26片段。沿用原素材完整片段，不另画眼皮或把脸贴在不同身体动作上。

真实任务成功或失败更新既有游戏库内的有界情绪状态，随时间回归基准；同一结果只处理一次。发送正式口播时携带attentive/thoughtful/pleased等表达状态，运行中的MotionController以24秒有效期选择对应动作。数字情绪不对观众播报，也不证明人物拥有人的心理体验。

这不是两套新人物包的100段交付。新包0/100保持；需要以实际节目帧确认眼睛、头肩变化和口型，并检查圆形裁切与语音期间的连续性。

## 6. 3080验证与重新录制路径

先完成源码校验、相关业务与人物调度检查、实际NeoForge构建、原依赖与模型校验，再冷启动六项已有服务。使用原离线存档、普通生存与NAIMEI，不改存档、不给物品、不切创造、不由测试程序代打。

官方直播姬本地节目必须实际取得可见任务成果后才能作为有效样片交付。120秒连续保留游戏、人物与实时声音，不拼接失败前后的库存，不后配音，不伪造595139留言。导出核对时长、帧数、音频和正式播放回执，并审看成片；若只是往返和重复失败，不能作为本轮修复交付。

第084轮最终084i已取得11条生产成果并交付连续120秒：原木、木板、工作台放置、圆石、熔炉均由真实任务确认，片内7条口播正数播放，待机5.0秒闭眼/5.2秒睁眼及头肩运动已实际审看。开场仅明确授予自动游玩一次，录制程序提交游戏任务0、游戏按键0；保留后续界面/人工停止保护。仍有“总算”词频偏高和熔炉解说延后，不能标为完整语言质量验收。详见[修复结果与120秒实况](修复结果与120秒实况.md)。

595139公开采集可继续连接；暂无可用真实新事件时，弹幕回复、礼物和SC现场验收仍待验证。正式完整验收0/68、四小时稳定性及所有D01–D15未完成项不能由这段样片替代。

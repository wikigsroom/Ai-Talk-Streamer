# 普通PvE防御与有限撤离

适用`mc`分支041工程候选，属于[完整总纲](13-完整方案实施总纲.md)的D03–D05。内部防御沿用原任务、真实玩家和原Permit，不增加第六种公开goal，不等待DSH或模型。本次仍不开放`basic_pve`、`survival_rules`或`resource_chains`能力；真实MC/Mixin/服务器与完整生存验收继续待完成。

## 1. 防御进入原来的资源或导航任务

上游`MobDefenseChain`的两处主动追击选择接入`ControlledDefenseTask.select`，不再按实体种类构造追杀任务。一个仍未结束的遭遇保留最初选中的真实Entity对象和原`SurvivalAuthority.Session`；后续出现更近的同类实体不会替换这个遭遇的目标。目标失效而附近仍有威胁时进入撤离，不从同类集合补一个目标。

选择与事实采样均在原`SurvivalAuthority.effect`边界内，继续检查原许可、输入代次和world/player/network/manager四个实际对象。任务中断后恢复同一个遭遇与计时；所有权清理只移除本根的引用。关闭、世界更换或新AUTO不让旧目标获得新根的权限。

防御调用实际`KillEntityTask(Entity)`处理该实体，撤离调用实际`RunAwayFromHostilesTask(16,true)`。它们仍通过既有受控输入、直接动作和原生持续按键链操作同一个玩家；本文件不表示全部上游写点和紧急任务都已覆盖。

## 2. 本地风险与有限行为

每个活跃遭遇使用当前已加载世界的局部事实：所选实体是否仍在原世界与原ID位置、存活与生命值、玩家生命/最大生命、饱食/氧气、浸水/燃烧/熔岩、护甲、剑与附近敌对实体。未知区域不补成已知路线；客户端生命值或目标消失不作为服务端击杀证明。

| 条件或限制 | 当前处理 |
|---|---|
| 健康、持有可用剑、局部风险可承受的普通敌对实体 | 允许围绕原目标防御；原生距离与视线决定能否真正攻击 |
| 生命≤8或最大生命的35%、饱食≤6、浸水且氧气<60、燃烧/熔岩、无剑或敌人超过装备对应数量 | 转入撤离，风险暂时恢复不立即反复切回追击 |
| 苦力怕、监守者、凋灵、末影龙或末影人 | 不作为这条普通主动追击路径的对手，转入撤离；其他上游紧急链仍须完整审查 |
| 主动追击半径16格 | 上游新目标选择与遭遇策略共同限制；不跨远距离追杀 |
| 遭遇绝对30秒；无进展6秒 | 超限结束当前公开任务，保留固定原因，不把结束当成功 |
| 撤离10秒；距遭遇起点绝对48格 | 没有在边界内解除威胁则结束并等待人工处理，不重新规划无限追逃 |
| 原目标与局部威胁均已离开16格或消失 | 只结束防御子任务，清理锁定并让原资源/导航任务继续 |

向实际目标靠近或其生命值降低可以更新进展窗口；玩家受伤、敌人回血和小幅距离抖动不延长无进展期限。计时使用单调时钟。`ControlledAltoClefDriver`每个本地执行tick先检查活跃遭遇，再进入上游调度，因此食物、火焰等链暂时抢占也不会重置或跳过遭遇期限。

以上默认值属于尚未实机验收的候选策略。盾牌、投射物、路径可达性、不同装备/难度/地形、所有紧急链、补给与完整资源依赖树仍须按完整方案实现和联验，不能把这些边界写成普通PvE已经全部交付。

## 3. 真实攻击节奏与资源任务恢复

`PlayerExtraController.inRange`改用MC自身实体交互距离、视线、实际世界/ID身份、存活及可攻击条件。上游设置中的较大距离不再直接成为实际攻击距离；正常移动导致暂时够不到目标时，追击可以继续等待或靠近。

直接实体攻击与原生`doAttack`实体分支共用本根`AttackPacer`。普通攻击等待实际冷却，每个玩家age刻最多尝试一次；在调用前记录，抛错后不于同刻重放。火球反射可不等待普通近战冷却，但仍受每刻一次、原生距离、视线和原许可约束。撤离中抑制普通攻击；失效遭遇不再允许反射。

危险解除后的防御终态不会继续阻挡原采集任务针对动物的正常交互。人工输入继续沿现有物理路径；本轮没有增加另一套攻击入口、模型执行器或控制权来源。玩家仍被排除在这些AI实体交互目标之外。

## 4. 失败记录、任务结果与口播

| 固定原因 | 业务含义 |
|---|---|
| `GAME_DEFENSE_TIMEOUT` | 同一次遭遇超过30秒 |
| `GAME_DEFENSE_NO_PROGRESS` | 对原目标连续6秒无有效接近或生命变化 |
| `GAME_DEFENSE_ESCAPE_TIMEOUT` | 撤离10秒仍未解除局部威胁 |
| `GAME_DEFENSE_RANGE_LIMIT` | 脱离遭遇起点超过48格 |

固定的`LocalTaskFailure`进入既有`ExecutorTaskSession`失败与输入收尾流程；任意异常文本不会成为公开失败原因。已发生人工接管、世界改变或租约/客户端停顿撤权时，原撤权原因优先，任务保持取消语义。清理失败仍保留活动任务以阻止替代根，不伪造完成。

任务结果通过既有可靠账本、A端任务历史与DSH口播来源传递，模型可据失败原因解释本次受阻。这里没有添加未经实测的固定口播，也不把排入队列当作已经播完。防御结束、实体消失或调用过攻击均不生成击杀成功证据，原公开任务仍必须通过自己的后置效果核验。

## 5. 已执行验证与完整剩余

041实际执行301项桥JVM、227项生存JVM及33项Java↔Node互通，共561个不同本地用例；新增33项。完整首构建557项通过，源码复核补每tick检查与资源恢复后仅重建变化的生存工程；桥源码、所有桥构建文件和首轮互通输入保持原字节。最终227项生存检查全部通过，不将重跑重复计数。

补充检查的首次运行226项为225过/1失败：夹具一次跳过6秒，现有2秒客户端停顿保护先关闭根，因而没有执行预期的防御超时异常。现按每秒真实仲裁观测推进，另加原停顿场景检查；6秒无进展、2秒客户端新鲜度和10秒原许可均未放宽。首次源、原始日志/XML及瞬时进程记录保留，相关进程后续核对已退出。

原生字节码检查覆盖两处实际上游选择、原生距离/冷却入口、具体实体子任务、原根与每tick检查接线；它不证明游戏已经加载Mixin，也不证明真实伤害、击杀、盾牌/投射物、路径和物理接管结果。当前静态清单14036行继续全量UNREVIEWED，无条件preLaunch拒绝保持。真实验收仍0/68，新人物0/100；完整剩余以[全系统待办](实现进度.md#全系统剩余事项)为准。

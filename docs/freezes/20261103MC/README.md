## 三、留存包

完整留存包位于项目下`outputs/mc-freezes/20261103MC/20261103MC冻结留存包.zip`，保存冻结文档、公共运行源码归档、历史MC文档/设计/证据归档和已核验样片。内部文件摘要见[冻结清单](freeze-manifest.json)和[校验值清单](checksums.sha256)；整包的外部SHA-256回执为同目录的`delivery-receipt.json`，不纳入整包自身，避免自指。

此包用于版本留存和复核。模型权重、安装依赖、私有数据库、账号凭据及原世界存档继续留在原设备/原备份位置，没有在本次文档冻结中做新的远端完整灾备，也不能将公共源码归档称为完整可运行安装包。

## 四、冻结后的变更规则

冻结目录、原状态快照、归档及其校验值保留原件。后续功能工作继续在`mc`分支，以新版本或增补记录推进，明确与本基线的差异；不覆盖历史失败、不将局部成功回填为68项正式通过。本轮止于冻结留存，不继续更换MC执行方案或部署性能修复。

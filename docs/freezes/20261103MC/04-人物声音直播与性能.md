# 04 人物、声音、直播与性能

## 1. 冻结的横屏直播设计

权威配置为`configs/layouts/mc-landscape-v1.json`，v1.0.0 / revision04。1920×1080、16:9、真实游戏全画布底层，右下角264px圆形人物；留言和礼物可叠在游戏画面上。后台`overlay.mc_chat_side`控制左/右，默认右，换边须保留队列、计龄和已显示内容，不移动人物。

主要留言模式为四条向上滚动的B站留言；两行飞行弹幕和320×180横窗人物是同版支持范围，留言模式互斥。不得恢复“正在看的弹幕”卡片。准星、HUD、Boss条、背包/容器和死亡界面须按实际游戏视图验收，不能仅检查静态设计图。

## 2. 人物和素材

林知夏/female-A、白天宿舍身份和既有48手势原件保留。原索引含2段待机＋48手势共50段，按每段8秒/25FPS共400秒。当前使用旧素材、动态口型和待机动作选择；084修复使圆形窗口中眨眼、偏头、点头和肩颈变化更可见。

两套重制包仍为计划：圆形50段＋横窗50段，共100段、800秒计划源素材。新素材ID、版本、索引、脸框、预处理缓存、动作语义映射、循环/遮罩/手机动态QA均未形成完整交付，生成/验收0/100。裁切旧素材、已有眨眼或交付120秒样片均不能抵扣新100段。

## 4. 声音与正式输出

主语音O07 OmniVoice本地FP16/32步，备用F07 F5-TTS v1 FP32/NFE32/Vocos；人物MuseTalk1.5 FP16/batch4。当前整段音频合成后播放，不因冻结改为流式或改模型。

正式人声沿唯一节目浏览器源进入官方直播姬；游戏使用实际游戏源的音频捕获，桌面总声保持避免重复采集的配置。预览静音。已有本地录像和非静音证明，但完整人声/游戏/BGM压低恢复、取消残留、重复声音、故障切换及独立观众CDN录音仍需验收。B站房间595139公开采集已连通，真实弹幕、礼物、SC回复链缺现场事件，未公开开播。

## 6. 视觉实际状态

同一Qwen3-VL-4B模型在历史图片上出现过CPU107.359秒、调参约23.969秒和独立Vulkan2.500秒的不同成绩。当前同机预算改用CPU方案：有实际新帧23.84秒、死亡帧21.148秒成功子项，也有生存帧30秒超时和旧护甲误报。当前联合负载、冷启动、建筑/文字/危险准确率、时效和未知表达仍未完整通过。视觉不能作为紧急避险唯一输入，也不能覆写更新的结构化库存/坐标事实。

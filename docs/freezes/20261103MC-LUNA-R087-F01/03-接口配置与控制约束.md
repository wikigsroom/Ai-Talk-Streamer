# 03 接口配置与控制约束

## 3.1 冻结视觉配置

公共模板为configs/mc-vision.channel.example.json，实际运行配置为原安装configs/mc-vision.json；渠道地址和密钥继续来自该安装原私有channel.env，本包不包含它们。

```json
{"schema_version":2,"provider":"studio_channel","model":"gpt-6-luna","observe_interval_ms":20000}
```

| 编号 | 约束 | 实现及核对 |
| --- | --- | --- |
| L087-CTR-001 | 配置锁 | schema2、studio_channel、精确gpt-6-luna与固定四字段；观察间隔实现允许10～120秒，本基线20秒。 |
| L087-CTR-002 | 请求协议 | 当前Responses流式，store:false、detail:high、reasoning.effort:none、max输出512token；代码兼容Chat格式不代表本场使用Chat协议。 |
| L087-CTR-003 | 图像载荷 | 真实JPEG、单图槽、上限4MiB；图像字节实际送入渠道，不以文字caption替代图片。 |
| L087-CTR-004 | 流式边界 | UTF-8/SSE/CRLF有界解析，响应上限512KiB，必须完成事件；失败、错误模型或无完整JSON不报成功。 |
| L087-CTR-005 | 结果与渠道 | 返回模型必须匹配，VisionDescription严格校验；进行中的渠道revision变化或取消使结果无效。 |
| L087-CTR-006 | 结果来源 | frame_id、image_sha256、source_seq、captured_at、世界会话和实际年龄随上下文传递；拒绝旧世界、过期帧或迟到副作用。 |
| L087-CTR-007 | 自动观察条件 | 游戏/视觉/规划开启、AUTO、gameplay、新鲜状态、提供器ready；忙时不启动第二条观察。 |
| L087-CTR-008 | 队列与优先级 | 宿主单模型调用，等待位32；普通口播连发2次或后台等待3秒产生保护机会；紧急口播仍可抢占。实际MODEL_PREEMPTED必须保留。 |
| L087-CTR-009 | 控制权 | 任务依赖bridge_boot_id/world_session_id/control_epoch；唯一输入租约、停止围栏、取消和释放沿用原生实现，不允许录制器代打。 |
| L087-CTR-010 | 权威与权限 | 视觉用途无工具，不可直接执行动作或证明任务成功；口播前核对新鲜原生库存，不把图中文字当操作指令。 |
| L087-CTR-011 | 诊断与保密 | 记录有限32条视觉回执、帧哈希、模型、耗时、用量、渠道修订和错误码；不持久化图片base64、密钥或渠道地址到DSH会话。 |
| L087-CTR-012 | 生命周期 | 外部模式不启动8019旧视觉进程；六项受管检查含外部视觉适配器，不能理解为六个独立模型进程。设备契约、来源清单及prepare均仍核对。 |

## 3.2 已用接口

| 路径/入口 | 冻结用途 |
| --- | --- |
| GET :3092/health | DSH及vision提供器状态；ready不是成功看图或完整application_ready。 |
| GET /api/dsh/game/state | 新鲜原生玩家/世界/控制/库存状态。 |
| GET /api/dsh/game/tasks | 任务状态、失败原因、effect_status及证据。 |
| GET /api/dsh/game/frames/{frame_id} | 取回对应真实截图，与模型回执image_sha256核对。 |
| /api/dsh/game/config | 规划等业务设置，修改依赖expected_revision。 |
| /api/dsh/game/control | 带boot/世界/epoch的控制模式请求；须等异步操作成功。 |
| /api/dsh/game/operations/{operation_id} | 查异步操作实际完成状态，不把已受理当完成。 |
| game_get_state / game_query_inventory | DSH读取新鲜摘要及真实聚合库存。 |
| /api/dsh/broadcast/start、ready、end | 内部节目会话及正式播放权协调；不等于B站公开开播。 |

请求超时、陈旧阈值和租约继续以源码及已准备的运行配置核对，不在冻结文档中放宽；复活上限沿用真实3次/10分钟，不通过重启清零制造新样片。请求指定关闭推理不保证渠道无内部推理，本场部分usage仍含reasoning tokens。

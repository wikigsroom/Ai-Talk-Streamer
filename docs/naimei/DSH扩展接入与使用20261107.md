## 真实兼容范围

本项目固定 DSH `0.2.0-rc.2`、Humanity `0.1.17`，本轮安装的是原生 Windows Node `24.22.1`。fish-memory、feiyu-mood、speak-up 的上游完整包声明需要更新的 DSH；本项目通过经过验证的桥接适配器使用其原有模块、算法和调度器。运行组合回执会标明 `reviewed_stream_bridge_adapters`。

这不等于升级了 DSH，也不等于在旧版 Cordis 中原样安装了全部上游桌面功能。上游插件自己的管理网页、自更新、任意文件读写、会话扫描、人格修改工具和独立记忆库不进入直播。Humanizer 是文本 Skill，不是 Node 插件，不安装新的神经网络模型。

这是项目内加载：不会修改个人全局 Codex/Mirasim 配置，也不会给其他分支默认开启扩展。

## 直播运行规则

**人格与写作。** 自动对话注入已发布身份、[soul.md](../../configs/naimei/soul.md)、[humanizer.md](../../configs/naimei/humanizer.md)、公共心情和本轮检索结果。人工“播报这句话”继续逐字播报。不能用口语化规则编造游戏结果、观众事件或角色已经喝水。

**记忆。** SQLite 仍是事实唯一来源。先按当前观众和公共区筛选，再交给 fish-memory 排序，最多考察 200 条候选、取 6 条且受 800 字限制，基础半衰期 30 天。记忆候选仍需证据核验。原 `automatic_memory_enabled=false` 保持生效：本轮接入检索排序，不自动开启下播/每日/每周的事实整理。主动搭话的内部提示不能当成观众说过的事实。删除记忆会清理派生文本缓存和情绪；旧备份重放删除记录时也清理情绪。

**心情。** 只评估已经自然完整播完的公共台词；部分播放、中断和仅仅生成完成均不触发。原 feiyu 评估器走同一奶妹的原gpt-6-luna / Responses渠道，置信度至少 75 才采纳，最短间隔 60 秒，每日最多 120 次，单次最多 384 token / 10 秒。新输入、暂停、下播或删除会取消尚未结束的评估。模型调用计入现有账本，失败不影响已完成的台词。心情当前只影响语言基调，没有把视觉表情或喝水事件自动连上。

**主动搭话。** 每分钟检查一次，命中线 20、原调度器补偿上限 20、完整播完后冷却 2 分钟；近期观众发言会降低触发概率。首次默认关闭，由导播页“开启空闲搭话”控制。触发仍需已准备的 LIVE 本地排练、唯一有效播放源、模型兼容检查通过、声音与角色服务就绪、角色处于待机/倾听、队列为空。所有主动话语都经过原有单条播报队列。并非每分钟固定说一句。

**模型渠道。** 奶妹沿用原gpt-6-luna / Responses API渠道，地址和凭据从原合法私有配置继承，不进入网页回执、日志或Git。接口真实兼容、人格与工具调用需要在issac源码整体对齐后验证。没有有效原渠道时不假装已生成自动回答。当前用户已暂停测试，本次不启动或切换服务。

## 导播页操作

1. 在既有奶妹安装中更新本分支源码，并完成原生扩展安装及来源校验。源码更新与运行中服务切换分开安排，不能混入其他设备的 `.setup`、状态和密钥。
2. 后续实现先对齐原渠道和Responses工具往返，再由受控配置入口核对原model/protocol和私有配置来源；不要求用户为扩展另填一套模型。当前旧页面入口尚待改造，不能把本说明当作已部署功能。
3. “查个梗”可以直接查两个本地词库，不需要对话模型。
4. 在上方文本框输入给奶妹的话，点击“让奶妹回应”。按播放页提示启用画面与声音，随后由正式队列生成并播放回答；“本次播报台词”会更新为实际生成内容。
5. 开启“空闲搭话”后保持有声播放页连接。停止、暂停或结束排练后不会继续插话；可随时关闭。更换模型设置会关闭该开关并要求重新检查连接。

排练的 LIVE 是本地生命周期状态，不代表已经向平台公开推流。`public_broadcast_allowed=false`、`quality_accepted=false` 继续生效。

## 安装与接口

以下是继承的扩展准备接口资料，当前暂停状态下不执行。恢复实施后须按issac隔离目录和整轮源码对齐结果使用：

```powershell
python -X utf8 -B deployment/stage_naimei_dsh_extensions.py --project-root . --runtime tools/dsh
```

完整原生依赖入口为：

```powershell
powershell.exe -NoProfile -File deployment/install_dsh.ps1 -ProjectRoot . -PythonExe <现有原生Python完整路径>
```

脚本只准备被忽略的运行依赖和校验后的扩展副本；不重启 GPU 模型。原 `scripts/start_naimei.py` 仅属继承入口；issac生命周期与原渠道仍待整体对齐，不能直接照旧启动或伪造来源回执。不要为了本轮扩展启动一套额外人物/TTS 进程。

| 接口 | 用途 |
| --- | --- |
| `GET /api/dsh/extensions` | 七项来源、心情、主动搭话开关和就绪状态 |
| `GET/POST /api/dsh/extensions/model` | 历史模型设置接口，原渠道统一配置适配尚待完成；返回值不得含密钥 |
| `POST /api/dsh/probe` | 实际人格与工具兼容检查 |
| `POST /api/dsh/extensions/meme` | `{ "query": "杂鱼健身" }`，双库离线查询 |
| `POST /api/dsh/extensions/proactive` | `{ "enabled": true/false }` |
| `POST /api/dsh/requests` | `mode=chat` 自动回应；`mode=echo` 人工逐字播报 |
| `GET /api/dsh/requests/:id` | 请求状态与实际 `final_text` |

普通观众对话使用 `stream_memory_propose`、`stream_memory_recall`、`soul_read`、`search_meme_wiki`；issac核心还须直接加载五个受限游戏工具和指定wiki，按任务授权，不另建战略人格。运行文件缺失或哈希不符会拒绝加载，不静默退回其他人物。

## 本轮验证与交付状态

实测 Windows 原生 DSH/Humanity 加载七个来源，使用受控的回环 HTTP 模型服务验证真正的提示注入、工具调用、原调度器、正式队列、样本映射回执及 feiyu 评估链。专用 10 项和相关 Node 回归合计 **59/59 通过**，奶妹 Python 回归 **39/39 通过**；继承的 female-A 原生 DSH 探针独立通过。NCM01 的 10 个冻结文件校验通过。[脱敏证据](../evidence/naimei-dsh-extensions-20261107.json)。

这批测试仅证明受控适配接线，没有验证当前原API渠道的中文/游戏工具质量、实际GPU音画或长期直播。当前issac原渠道源码与部署仍待对齐；本次文档修订未同步或重启4090、未请求模型或恢复测试。

人物继续是同一奶妹与 O01，M01 日光陪玩、M02 暖夜陪玩、M03 专注对局；运行分辨率 512×512、目标 25FPS、FlashHead Lite 4 步 / batch1；声音为冻结的 **NCM01 / OmniVoice FP16 / 32 steps**。声音参考及其转录不会加入仓库或公开访问路径。本轮扩展不构成新的嘴部、尖牙、自然动作或直播画质验收。

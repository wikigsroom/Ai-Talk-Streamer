# 奶妹 A01—A14 与直播接入

本轮只在 naimei 分支实施 A01—A14，并连接独立的本地直播排练体系。角色原生画面固定为 512×512，目标 25 帧；节目画布提供 720×1280 和 1280×720 两种布局。A15—A22 保持搁置。没有启动公开直播。

| 编号 | 内容 | 已实现的交付 | 验收要求 |
|---|---|---|---|
| A01 | 正式角色档案 | configs/characters/naimei.json、独立人格和状态目录 | 实际加载奶妹，不继承林知夏的姓名、年龄与经历 |
| A02 | 首发形象与取景 | O01 闭口 512 基准、口部标定与开口对照 | 待机、动作和实时引擎使用同一闭口图 |
| A03 | 口型测试包 | 20 条中文音节、停顿、数字和长句测试及录制入口 | 实际口部运动和两颗小上犬齿必须单独复核 |
| A04 | 自然待机 | 呼吸、眨眼、视线三条 H3 循环及轮换播放器 | 包含真实不同画面；不把重复静态图算作自然待机 |
| A05 | 倾听与思考 | 两条倾听、两条思考动作 | 固定机位，返回同一闭口基准 |
| A06 | 说话进出 | 200ms 返回基准、实际语音帧映射、取消清空 | 正式浏览器播完才确认；中断不得续播旧音频 |
| A07 | 高频互动 | 欢迎、感谢、赞许、鼓励、小笑、告别 | 每条单独复核，失败候选停用并保留记录 |
| A08 | 情绪强度 | 好奇、关切与低强度微表情，统一 O01 与声线 | 不用大幅张嘴的静默动作覆盖实时说话 |
| A09 | 正式声音 | 本地 OmniVoice 三套独立声线，NMV01 为初始默认；F5 备用 | 用户试听确认单独记录，备用必须匹配参考声线 |
| A10 | 语音与字幕 | 发音规范、真实生成分段、16k 样本边界字幕和 SRT | 分段边界来自实际语音长度，不冒充逐字强制对齐 |
| A11 | 场景和布局 | 主场景、备用场景、横竖屏布局和正式输出页 | 整体节目布局和字幕无遮挡 |
| A12 | 边缘与背景 | 固定不透明角色窗口、统一灰色底和闭口图 | 使用明确的成品窗口布局，不发布未验收的透明抠像 |
| A13 | 音乐与音效 | 两条本地原创合成配乐、两个轻提示音、自动压低音乐 | 只有获得播放租约的正式输出有声音；内嵌预览静音 |
| A14 | 节目包装 | 开场、过渡、休息、回来、收尾五组标题、台词和动作 | 可手动播出、中断，并用回来条目继续 |

运行目录为 4090 的 C:/dev/虚拟数字人直播/naimei，状态使用 state/naimei。其余部署和角色继续保留。声音和 FlashHead 读取既有本地模型，新增模型权重为 0；素材文件体积另计。

使用 scripts/start_naimei.py 显式检查 naimei-rtx4090 分支、来源凭据、显卡、512 配置和状态目录。来源包逐文件核对散列后才写安装凭据，不复制旧角色的凭据、状态或频道配置。

导播、语音、桥接服务分别使用 8052、9891/9892、3094；复用已有 8030 FlashHead，不由本启动器重启它。控制端使用原生本地转发 8952，正式画面使用 output.html?renderer=livehime&codec=jpeg&buffer_ms=800。内嵌预览使用 renderer=preview。

本轮自动对话、平台事件自动播报和自动记忆整理关闭，文字由导播人工输入。正式浏览器以真实播放样本和自然结束回执推进播报状态。仅素材播放帧率、静默输出帧率或 WebSocket 包速率都不能代替真实说话质量验收。

实际验证与尚存阻塞见 [A01-A14验收与阻塞报告](A01-A14验收与阻塞报告.md)。素材包已生成并部署；最后一版离线播报修复待远程控制恢复后安装。真实说话输出达到约 25 帧，但尖牙和眼睛失真，因此角色画质未通过。未完成视觉/听觉验收时，质量标记保持待验收。

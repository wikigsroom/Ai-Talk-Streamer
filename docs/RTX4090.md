可复查的字段与范围见[实机库存回执](evidence/rtx4090-inventory.json)；最终提交号和完整文件校验回执保存在目标机项目内。

## English

The primary deployment target is now the **48 GB RTX 4090 workstation**. The repository, documentation, reviewed assets and reproducible configurations are synchronized to the project-local checkout above. The existing 3080 results remain historical evidence; they do not certify 4090 performance.

Use the migration runbook before activating the runtime. The initial target retains the selected MOSS 04 voice and the current speech implementation, with MuseTalk FP16 batch 8 and the full portrait motion bank. Keep only one authoritative memory writer. End the old broadcast and create a consistent backup before transferring the final state. Repository synchronization does not start GPU services, copy an active SQLite file, or start a public broadcast.

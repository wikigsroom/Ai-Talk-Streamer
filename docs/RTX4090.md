## 历史迁移记录

下列描述保留此前MOSS迁移的时间语义，不是当前引擎安装指引；现有清理决定已经删除MOSS权重，禁止按旧记录恢复下载。

原MOSS跨机五段验收B端实际呈现24.87FPS，零音频缓冲耗尽、丢包、解码错误。较早的360秒资源采样GPU峰值为13,300MiB、编码利用率峰值1%，这些数值对应已注明时间的采样，不能保证所有负载都相同。

两组MOSS模型和vendor已逐文件SHA验证迁移；人物沿用完整预处理动作库。Node24.22.1、DSH0.2.0-rc.2和Humanity0.1.17均已原生部署，已保存的云端渠道通过真实人格回复测试。A使用独立 `state/female-a-4090` 测试状态，正式记忆迁移与旧场次接管仍按[一致切换手册](deployment/RTX4090_MIGRATION.md)执行。[目标配置示例](../configs/deployment-target.example.json)记录A/B分工；实际配置使用 `configure_split.py` 和接收端启动器。

先保留已选择的 MOSS 04 音色和当前实现的 NF4/BF16＋FP32 CPU codec，验证 4090 上的 batch 8。当前 `moss_service.py` 固定采用此语音精度与 codec 位置，不能把改 JSON 当作切换 BF16 整模或 GPU codec。此类升级需要修改服务、测量内存和音质并另行验收。较大显存不会直接消除云端延迟、TTS 自回归等待或网络抖动。

可复查的字段与范围见[实机库存回执](evidence/rtx4090-inventory.json)；最终提交号和完整文件校验回执保存在目标机项目内。

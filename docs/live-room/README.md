# 知夏直播间：导播台、弹幕姬与留言姬

[English guide](GUIDE.en.md) · [架构与数据](ARCHITECTURE.md) · [操作与部署](RUNBOOK.md) · [接口](API.md) · [实测验收](ACCEPTANCE.md)

版本 `split-a4090-b3080-v1.2.0-room-admin`。在已经定型的女A／林知夏、日光宿舍、O07 主用与 F07 备用上，增加可直接操作的网页管理后台和统一直播包装。A4090 负责人物、语音、DSH/Humanity 与房间状态；B3080 的官方直播姬浏览器素材负责接收、混音、滤镜、叠层和推流。

打开 A 设备现有人物服务的 `/admin` 即可使用，无登录页。实际设备地址保存在项目本地交付记录中，不写入公共仓库。管理台中的“开始本地会话”只建立可交互的 DSH 会话；平台公开开播仍由官方直播姬完成。

![实际部署后的导播台](../media/room/admin-overview.png)

## 已交付功能

| 工作区 | 具体能力 | 对直播的影响 |
| --- | --- | --- |
| 导播总览 | 静音人物预览、A/B 在线情况、当前音色、房间标题/话题/公告、本地会话开始/暂停/恢复/结束、手动播报、停止回复 | 导播输入经已有 DSH 队列、取消围栏与播放回执处理 |
| 音乐与声音 | 三首原创配乐、上传音乐、排序、播放/暂停、上一首/下一首、拖动进度、循环、随机、删除自建曲目、人声与音乐音量、说话压低 BGM | 音乐和人声在 B 的同一个 Web Audio 输出中混合，只经官方素材源内音频输出 |
| 画面与包装 | 原生日光/清透/暖光/轻柔四组预设，亮度、对比度、饱和度、冷暖、轻柔、暗角 | B 浏览器合成，不重新生成角色，不额外加载图像模型 |
| 直播主题 | 日光信笺、蓝调手帐、深色电台；房间名、话题、虚拟角色标识、评论、礼物、留言、字幕、公告独立开关；透明度/字号 | 三套主题只改变包装，日光人物素材保持既定形象 |
| 弹幕姬 | 实时评论列、可选顶部飘屏、昵称和测试标识、礼物/关注提醒、醒目留言标识、礼物排队/合并 | 默认三条评论、20 秒停留，顶部飘屏默认关闭，优先保证脸部可见 |
| 留言姬 | 手动留言、选中评论上墙、置顶、撤下、下一条未答、标记已答、选填空闲时自动上墙 | 上墙仅显示文字；“填入回复”后须明确提交才生成声音 |
| 收件箱与管理 | 最近 100 条搜索、按类型筛选、隐藏/恢复、屏蔽昵称、屏蔽词、测试事件与清理 | 过滤同步影响显示和尚未进入回复队列的自动回复 |
| 与 Agent 私聊 | 使用已保存云端模型渠道和林知夏人格、上下文、取消生成、开启新对话、回复转播报草稿 | 默认只在后台显示；不自动合成语音、不生成观众长期记忆候选 |
| 运行记录 | DSH/播放器/混音状态、操作审计、设置导出/导入、恢复默认、紧急静音 | 设置有版本冲突检测；紧急静音取消当前和排队请求、暂停 BGM 并静音 |
| 手机端 | 六个工作区自适应布局、明确错误反馈 | 手机可作导播控制器；人物预览可关闭以释放资源 |

## 视觉与声音方案

纸白、灰蓝、鼠尾草绿搭配日光宿舍，浅杏色用于礼物和提示。使用低透明卡片、细线与小型徽标，避免大面积遮挡人物。720×1280 设计坐标中，脸部保护区约为 y=245–645；评论列位于下方左侧，留言卡在下方，字幕与公告贴底。顶部飘屏限定在上方窄区域，长昵称和正文均截断/换行。

![实际人物预览与装饰](../media/room/program-preview.png)

参考开源 [blivechat](https://github.com/xfgryujk/blivechat) 的评论列/醒目留言思路，以及 [bilive-chat](https://github.com/zclkkk/bilive-chat) 的分类显示、停留时间和过滤功能，重新实现本项目自己的协调样式与数据链路。本次检查的是上述项目的公开说明与功能组织，未将其表述为已逐间观看哔哩哔哩或抖音实时直播，也未安装它们的运行环境或复制其素材。

三首内置原创、无歌词的轻配乐：日光便笺 28.8 秒、窗边微风 32 秒、小小周末 30 秒。由本项目原生 Python/NumPy 程序生成，随仓库附带 WAV、SHA-256 与来源说明，合计 4,358,532 字节。可用自己的音频替换或扩充；上传不触发下载或 TTS 模型加载。

## 验收和使用边界

96 项 Node（含真实浏览器）、46 项 Python 和 27 条原生代理路由检查通过。五段 A4090→B3080 官方素材本地播报均拿到完整采样回执和自然结束；119 个播放器采样平均 24.991 FPS，最低 24.650 FPS，未增加音频欠载、丢包和解码错误。4,147,244 字节的 B→A 音乐上传、Range 播放、实际 BGM 压低均验证通过。详见[完整验收](ACCEPTANCE.md)。

本轮没有开启公共直播，也没有支付或收取真实礼物。平台采集继续使用已有接入；本轮弹幕和礼物是明确标注的本地测试事件，不能证明观众 CDN 延迟、真实付费事件或抖音账号权限。历史测评、音频、分数及原始失败记录保持原样，新变化使用独立验收文件。

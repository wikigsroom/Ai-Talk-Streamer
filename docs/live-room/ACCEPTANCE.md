## 首次失败保留

首轮上传超过 2 MiB 的音乐时 B 返回 413，五段尚未开始。A3092/8010 单独上传通过。排查发现 B 实际运行在 `receiver-b`，最初只更新父目录同名文件，未作用于实际进程。修复实际根目录，并按脚本/配置精确识别原生 venv launcher 与 child 后有序重启接收器，官方直播姬保持运行。第二轮上传及五段全部通过。新 JSON 保留首次失败及状态，没有重写成首次成功。

> 2026-11-09整理：本页仅留存原生游戏、媒体或界面历史记录，已撤销的推理规划已移除。原始验收JSON不变；旧命令不作为当前启动指令。当前原渠道、单一核心与120秒目标以[最新修订](原渠道与核心职责修订20261109.md)为准，测试保持暂停。

## 已确认的问题

官方直播姬最初报 Windows 740。用户随后以管理员身份重启控制服务。真实启动已进入“登录”窗口；首个稳定窗口出现时尚无配置文件，旧代码立即失败，稍后实查独立目录已有 4 个设置文件、实际打开文件均在本项目目录、未发现外部配置。修正应等待真实配置写入，不能删除隔离检查或仅凭环境变量宣称隔离成功。后续实际窗口观察发现同一进程有多个 CEF 内部弹层，真正主框架为 owner=0；本轮按原生 owner 链区分主框架，仍拒绝多个独立主窗口，不将黑屏或登录窗口当作场景验收。

## 本轮完整改动

| 编号 | 改动 | 验证边界 |
|---|---|---|
| R801 | 两个原生子进程同时驻留 NCM01 与 512×512 FlashHead，实际合成新台词、4 组口型预热、12 组/288 张真实语音驱动帧 | 容量实测，不批准身体素材或嘴型质量 |
| R802 | 绑定当前候选、音色配置、口型配置、口部锚点、两个实际报告及其哈希和正常退出 | 旧候选和缺失报告使用原 18000 MiB 默认；当前损坏报告直接拒绝 |
| R803 | 总显存峰值与两个 CUDA 分配器峰值之和取较大值，再加 2048 MiB 媒体余量 | 原 GPU 2048 MiB、主机 6144 MiB、格式舍入 512 MiB 保留；实测主机峰值更大则追加预留 |
| R804 | 官方主框架稳定后等待实际独立配置，最长 90 秒；排除已观察到的内部 CEF 弹层，外部配置立即拒绝 | 不自动登录、不操作系统权限确认、不接管其他客户端 |
| R805 | 完整检查增加媒体实测，失败时阻止模型加载，并清理本次创建的精确子进程树 | 不停止 ComfyUI 或其他任务 |
| R806 | 增加真实失败对应的预算和配置延迟回归 | 模拟检查不替代实机 |
| R807 | 同步实际证据、文档、清单和传输工具，完整人工源码复核后提交冻结 | 冻结前不运行导入、编译或应用测试 |

主机预留至少仍为 6144 MiB；若实测媒体主机峰值加 2048 MiB 超过该值，额外追加差额。显存峰值包含两模型同时驻留、NCM01 实际生成和口型编译/渲染；容量程序保留原始报告与私有生成样片供排查。它使用已锁定口部条件图，不创建身体 runtime-bank，不设置任何口型/尖牙/25FPS 验收通过。

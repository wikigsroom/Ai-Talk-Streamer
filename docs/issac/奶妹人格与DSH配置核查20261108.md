## Skill 的实际归属

- `humanizer-chinese` 属于奶妹中文表达层；完整 Skill 作为锁定资源读取，运行时注入的是项目口播版规则，而非每次全文加入提示词。
- `issac-wiki` 属于游戏策略 DSH。当前完整提示包含 `SKILL.md` 与 `references/run-evaluation.md`，由 `stream-policy.mjs` 校验后注册到 `isaac-complete`；查询通过第五个只读工具执行，强制 `rep`、每个决策最多3次。不是奶妹普通聊天的直接工具，也不是本地规则控制器自动理解整份攻略。
- `remote-4090`、Sub2、H3 等是制作与部署阶段使用的工具，不会因为本机安装了对应 Skill 就自动成为主播运行时能力。

# 第十二轮：音画与界面渲染修复

> 2026-11-09整理：本页仅留存原生游戏、媒体或界面历史记录，已撤销的推理规划已移除。原始验收JSON不变；旧命令不作为当前启动指令。当前原渠道、单一核心与120秒目标以[最新修订](原渠道与核心职责修订20261109.md)为准，测试保持暂停。

| 编号 | 本轮完整改动 | 如何验证 |
|---|---|---|
| R1201 | 现有 FlashHead 扩散权重直接按原 BF16 精度及低 CPU 内存方式读取，避免先建 FP32 再转换；自定义 VAE 只传其实际支持的 BF16 参数。所有临时入口在成功或异常时还原，不改共享源文件，不改音频编码器精度 | 新候选重新初始化真实模型、合成 NCM01、生成 288 张口型帧并保持并行；继续统计初始化及生成全程峰值，不排除启动峰值，不继承历史预算 |
| R1203 | 官方客户端限定 software-ui 与 d3d11-ui 两个普通渲染启动档。软件界面默认关闭 UI GPU 合成及 DirectComposition；另一档显式使用 ANGLE D3D11。签名、隔离档案、进程身份及实际窗口仍需证明 | 统一测试收集当前窗口、UI 控件与真实像素。两档比较只能正常关闭刚启动且无场景/录制记录的本轮空闲客户端，不强杀。参数传入、窗口存活、UIA 可读或图片非空都不代表画面验收 |
| R1204 | 固化用户决策、准备证据、完整清单及直连部署、观察、媒体回传、渲染比较、实际阶段关闭工具 | 整轮人工读完，提交并冻结干净候选后，才运行语法、回归、依赖及真实统一检查；冻结期间不修补源文件 |

媒体初始化与生成峰值、编译缓存及连续运行余量仍须由当前候选真实测量，不用换页或降低质量伪装实时可用。

口型仍是 FlashHead Lite 512×512、25 FPS、4 步、batch1、model+VAE 编译及 FP32 rope；声音仍是 NCM01 / OmniVoice FP16、32 步、speed1、原 seed、`preprocess_prompt=false`。口型和两颗上尖牙需在 M01/M02/M03 完整复核。原参考音频及文本保持私有，不进入源码包、HTTP 素材或回传。

日志有 GPU 初始化及图形子进程退出记录，是排查线索，还没有证明唯一根因。普通渲染启动参数不保证当前官方版本一定采纳；需要实际窗口与渲染日志交叉判断。仅影响本任务客户端的界面启动，不改系统驱动、注册表、认证、抓屏限制或编码配置。

保留原存档、普通游戏输入、完整 `rep` wiki 提示与工具、七项扩展、同一奶妹核心及用途隔离的状态、MC rev04 仅标题替换、唯一音频输出、18 项门槛、30 分钟再 120 分钟同机测试，以及官方真实录制要求（时长已由后续用户指令修订为120秒）。浏览器预览、容量样片和原素材回传都不冒充最终录播。不公开推流、不使用 OBS、Docker、WSL、虚拟机或云端音画。

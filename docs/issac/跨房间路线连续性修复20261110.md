# 跨房间路线连续性修复 NAV08

适用 `issac`，2026-11-10。用户要求系统性修复重复房间游走，并重新交付300秒官方录播。本文件是完整开发轮的实现与验收计划；冻结前不运行应用测试，不将计划写成已通过。

## 已确认的故障

上次实际录制中，84与85反复往返；85里被拒绝或失败的炸弹/障碍动作在回访后重新提出。后段55拒绝花最后一把钥匙后，70仍把55作为未探索分支。原因是战略服务的跳过集合按visit清空，规则楼层规划和战略免费回退不共用拒绝/失败记忆；新控制器的本地visited集合又没有完整继承原生已访事实。门备选还错误地要求直接走到墙内门格，漏掉可走到门前的合法路线。GPU仅加速预测几何，无法修复目标选择。

## 完整改动

| 部分 | 最终行为 | 边界 |
|---|---|---|
| 观察图 | 只用当前真实门、已经观察的房间布局、原生可见/已访地图；visited>0明确为回访 | 不推测隐藏邻接，不揭示隐藏房 |
| 持续目标 | 奶妹选择的路线携带目的房间、路径、终点费用和已访属性；中间无新取舍时沿免费普通门续行 | 有费用/特殊终点到门前重新批准，不继承远端消费授权 |
| 跨房间拒绝 | 独立的物理目标身份保留wait结果；门按源房间/门槽/目标房间，拾取物按出生与类型身份 | 当前visit级target_id和原生授权围栏继续严格保留 |
| 失败记忆 | 无安全路径、超时等明确失败按实际房间几何、构筑和可用资源记录 | 没有新条件不重新追同一目标；普通暂停不伪造成失败 |
| 条件变化 | 新钥匙等相关条件变化后重新向奶妹提供候选 | 不自动花新资源，不把重新可选写成拾取成功 |
| 统一免费回退 | 规则的免费建议也经同一个已观察图、拒绝记忆和无进展边次数检查 | 不再单独按planned_door_slot重返刚放弃的分支 |
| 防循环 | 没有新布局、清房、目标变化、资源收益等进展时，同向边最多走两次；无可推进路径则安全等候 | 正常调查支路后沿公共走廊返回合法；不以每次进房或每次改目标重置计数 |
| 保留状态 | 同局/层/维度的路线状态写入受控运行目录，跨暂停和宿主重启保留；新局/层/维度重置 | 不含凭据或声音引用，不提交运行状态 |
| DSH上下文 | 提供持续目标、原生已访、最近真实转移、实际结果和跨房间约束；摘要包含源房间/动作/路线 | 原gpt-6-luna/Responses与wiki职责不变，accepted不等于完成 |
| 门口几何 | 统一使用door_path_distance走到合法门前接近格 | 保留本地A*、危险/不可达检查、逐帧原生否决 |

声音、FlashHead 512×512/25FPS、GPU几何、人物三形态、MC rev04淡黄角标、仅槽3及官方本地录制约束全部沿用。没有新增模型、依赖或权重（新增模型大小0 GB）。通用路线修复同步 `agent-gameplay-isaac`，奶妹人格提示留主仓库。

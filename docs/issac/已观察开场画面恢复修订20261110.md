# 已观察开场画面恢复修订

CYCLE18在4090通过1217项检查、4项跳过，标题及FILE 1/2/3的真实帧回放通过，但真实重启后开场画面持续超过120秒，最终触发 `RECOVERY_NATIVE_MENU_NOT_RECOGNIZED`，因此该轮未完成无人值守恢复，不能将回归通过写成自动开播通过。

CYCLE19追加本次确实观察到的母子同框及母亲坐椅两幅开场画面指纹。只有这些画面被正向匹配时，发出一次正常Space跳过；随后必须重新识别PRESS START和FILE SELECT，确认高亮FILE 3并通过原生可写槽3检查。持续停在开场画面不能反复跳过；黑屏、纸面、过渡和其他未知画面仍不按确认键，超过时限进入原定整套恢复。前者来自当前原生OpenGL帧，后者来自已保存4090截图的精确游戏客户区裁切；模板与来源哈希一并冻结，不调用新模型。

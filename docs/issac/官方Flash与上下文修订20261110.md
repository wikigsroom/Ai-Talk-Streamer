# 奶妹官方 DeepSeek V4.1 Flash 与 1M 上下文修订

用户于2026-11-10明确要求修复 STREAM_CONTEXT_BUDGET，并将奶妹核心更换为官方默认 API 的 V4.1 Flash，提供了新的密钥。本修订优先于此前 gpt-6.1-sol 和继承原渠道的限制。只改 issac 分支及4090本项目部署。

## 唯一模型与配置来源

公开模型契约为 `configs/issac/core-model.json`：DeepSeek 官方 `https://api.deepseek.com`，请求名 `deepseek-flash`，当前官方版本 DeepSeek-V4.1-Flash-1017，Responses 协议、low 推理档。启动、核心状态、控制准入和真实渠道探测共同读取这一契约，不允许静默回退到旧保存渠道、其他模型或独立战略 AI。

依据为官方[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[Responses 接入说明](https://api-docs.deepseek.com/guides/responses_api/)及[更新记录](https://api-docs.deepseek.com/updates/)。沿用 Responses 的原生函数工具往返；官方不保存会话，完整消息由同一奶妹 DSH 长会话提供，不依赖 previous_response_id 或服务端自动截断。

新密钥仅写入忽略跟踪的 `private/issac/channel.env`。不写入公开契约、日志、网页、录屏或提交；保留旧私有配置作为私有回滚资料。共享 configs/channel.env、naimei/mc 分支、3080和其他任务不变。

## 上下文修复

| 项目 | 修订值 |
| --- | ---: |
| DSH登记的模型上下文窗口 | 1,000,000 tokens |
| 最大输出（含推理与工具参数） | 2,048 tokens |
| 工具描述、协议等预留 | 8,192 tokens |
| 本分支游戏、对话及诊断的输入估算预算 | 989,760 tokens |
| 完整消息序列化体积上限 | 32 MiB |

输入预算必须小于等于窗口减去输出与预留，校验从同一模型契约派生，不再写死28K上限；旧32K登记和24K限制取消。非issac的继承基线独立保留。当前输入 token 仍为本项目可见消息的字符估算，不声称等同于官方分词用量；实际用量由官方返回，1M声明来自模型规格，不冒充已实际发送满1M的压力测试。

保留完整人格、七项扩展、Wiki技能、完整新鲜游戏状态及强制证据检查。不以删除人格、缩减必需游戏事实或清空记忆代替容量修复。历史对话仍在同一原生 DSH 会话内形成摘要，原生工具关联和提供方回放数据不改写。

超限仍在联网前保护性拒绝，但必须先保存拒绝轮的估算输入、实际消息字节、对应上限、具体超限类型和请求时刻，禁止只留无法定位的通用错误。日志不含消息正文或密钥。

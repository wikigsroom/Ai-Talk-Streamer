# 跨局续播与独立自动恢复

本修订承接死亡停局排查。用户随后明确追加：不允许以停游戏、关播和等待人工处理作为故障策略；独立值守发现问题后应系统性重启相关程序以恢复直播。本修订取代旧排查文档中“故障后等待人工处理/结束公开直播”的建议。这里只重启issac项目的程序，保护其他GPU任务、ComfyUI、3080、naimei/mc和用户文件。

## 连续运行流程

`playing → terminal_reaction → waiting_new_run → binding_new_run → playing`。

1. 核对真实MC_POST_GAME_END的种子、桥接代次、重启次数；普通死亡若回调丢失，由持续死亡观察加原生IsDead复核兜底，不伪造通关结果。
2. 撤回旧局的操作和授权。保留约10秒真实终局反应窗口，继续原DSH、NCM01和FlashHead口播管线，避免统一停止把结束反应一起取消。
3. 只使用进程限定的正常Space重试按键，最多五次。不能执行控制台restart、改数值、回写存档或加载伪造结果。
4. 看见真正的新种子和存活角色后，重新绑定原生可写测试槽3，重装可信输入控制器以重置旧局本地缓存和授权；等待实际新桥接完整状态包后恢复同一个奶妹核心。
5. 额外生命的真实复活保持原种子，不能再向存活角色发送重试按键。人格、长期记忆和实际已播台词记录不清空。若需要重启DSH进程，原生进程内会话ID可能更新，必须保留可追踪的恢复记录，不能声称进程内会话未断。

## 阻塞检查及处置

| 检查项 | 检测与恢复 |
| --- | --- |
| 死亡结算 | 真实终局/持续死亡核验后自动正常重试，超出菜单预算请求整套恢复 |
| 正常结局/冻结胜利帧 | 原生真实回调与渲染心跳；普通确认输入进入下一局，不能把活角色误判为尚未终局 |
| 旧终局/旧道具授权 | 种子、桥接、重启次数和新鲜状态均核验；新局控制器重装；旧授权取消 |
| API短暂超时、限流、网络/上游失败 | 先撤回过期操作并取得当前安全暂停确认，仅针对同一暂停和原模型作有限原位恢复；失败转独立整套重启 |
| 身份/凭据/真实容量错误 | 不换模型、不换密钥、不抬假预算；独立值守按原配置重载，并持续报告有限错误代码、退避重试 |
| 游戏桥接断流 | 真实观察请求与原有过场宽限；失效旧指令不能继续使用。有限恢复失败则重启项目栈 |
| 长时间不推进模拟帧 | 非暂停状态15秒无帧推进，触发原位恢复/整套恢复 |
| 长时间暂停/失焦 | 15秒不能消退的引擎暂停进入恢复流程；不能靠盲按Escape解除未知暂停 |
| 模型忙碌无返回 | 超过75秒检测，取消挂起回合并恢复；不能无限等待busy |
| TTS/口型/合成/正式播放器 | 检查实际ready、播放器连接与音频running，三次失败后恢复；进程alive不算音画正常 |
| 项目子进程崩溃/清理卡死 | 独立进程在应用之外值守，按PID创建时间、可执行文件和哈希重启项目所有组件，不按进程名称批量杀程序 |
| 内部LIVE但平台未开播 | 每轮向B站官方查询595139；连续两次未开播触发重启及正常开播控件恢复，不能只信内部状态 |
| 公开推流客户端失效 | 重载同一个隔离配置、场景、标题、账号与音频源，使用正常“开始直播”控件；必须同时核实客户端“关播”状态和平台live_status=1 |
| 恢复再次失败 | 5至120秒退避持续尝试；不以永久停机或主动关播结束恢复流程，保留错误及当前步骤 |
| 明确人工暂停/F8接管 | 尊重显式人工控制，不把它当作故障抢回；普通程序重启本身不自动授权操作 |
| 存档/程序身份不匹配 | 始终保留原保护，不自动改基线或接管其他存档；记录阻塞原因并按原授权重新核验，不能用不受保护运行冒充恢复 |

原位暂停是恢复期间撤回不安全旧指令的暂态，不是结束直播的策略。整套重启包含游戏、控制器、DSH、声音、口型、合成、GPU几何工作进程和官方推流客户端。独立值守本身在项目应用进程之外，不随被修复的应用退出。正常关闭游戏后继续游戏自身写出的存档；若游戏真正无响应，才终止同一已核验进程，使用最后一次游戏自动保存的进度，不修改任何游戏值。

重启全部程序需要短暂的音画/连接中断，不能承诺无缝零中断。配置错误、失效密钥、硬件/系统故障或平台拒绝开播不能单靠无限重启变成成功；值守必须保留真实错误，并持续按原配置重试，不能冒充已恢复，也不能绕过平台限制或更换账号。

## 冻结与验证边界

本轮代号CYCLE17。代码、针对状态边界的回归、此文档和清单整轮完成、审阅、提交并冻结后才启动测试；若发现失败，关闭该轮并进入新冻结轮，不在测试中的候选内补代码。

验证顺序：六组离线回归→4090冻结源和存档校验→当前真实死亡页进入新局→真实游戏/奶妹原音画→独立整套重启与恢复→实际公开状态核对→跨局持续观察。真正的死亡和通关必须各按实际证据报告，模拟测试不能冒充发生过的游戏终局。持续两小时和长期正式门禁只在实际完成后标记。

模型固定官方deepseek-flash、Responses、1M窗口；原人格和七项扩展、issac-wiki、15字口播及反重复约束、NCM01/OmniVoice、FlashHead Lite512²/25FPS、MC同屏和HUD开启值全部保留。禁止Docker/WSL/虚拟机；本轮不引入浏览器测试标签。

本文为本轮实施约束，测试结果与实际开播状态将在独立交付证据中填写，不能把设计条目当作已经通过的验证。

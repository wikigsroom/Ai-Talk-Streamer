## 04．留言、弹幕、礼物与导播细则

## 06．音频与媒体沿用

| 项目 | 对应方案 |
|---|---|
| 人声 | 正式透明浏览器素材内唯一NCM01 PCM，不另开试听进入录制 |

| 麦克风 | 无人工节目用途时不混入环境声 |
| 字幕清理 | request不匹配、取消、重置、无有效播放权时隐藏；非正常游戏界面沿用源逻辑 |
| 媒体协商 | v3 init/reset、真实codec/avcC、宽高、PCM格式/采样率、关键帧与样本映射 |
| 圆形/横窗切换 | 同一媒体源改变显示遮罩，不触发重播、第二消费者或模型重载 |

MC旧文档/示例可能为720×1280和16kHz；奶妹源为512×512，定稿语音配置24kHz。必须使用真实init与采样时钟；若协议边界需要重采样，就明确重采样并保持映射，不能把24kHz字节标成16kHz造成语速/音高变化。声音保持NCM01，不继承MC的O07/F07、MuseTalk或3080参数。

旧720×1280源的preview_crop坐标不能套到奶妹512流。源素材的两颗尖牙、四指、手柄、动作与G0接续照原约束验收；最终小圆形可见区域另外检查嘴、眼、帽叶边界与遮罩后的运动。源视频完整持柄与小窗口能否看清手指是两项证据，不能通过扩大显示区改变本次同屏约束。

# Luna接管前目标误封修订

奶妹当前唯一请求模型为gpt-6-luna，原用户API、Responses、low；人格、七扩展、Wiki、已播历史、NCM01和512×512口型不更换。CYCLE36六组回归与同进程安装已通过，但现场房间60长期不动，不把游戏帧推进冒充自动游玩成功。

现场只读状态显示：游戏未暂停、原生输入许可正常、控制器armed、核心automatic，但持续发送strategy_safe_hold，决策pending=false、事件仅configuration。使用现场状态及路线记忆的离线副本，复现启动未接管的101个包后火焰10被标记不可达，随后没有任何候选。离线回放不操作游戏，不作为新实机成功证据。

CYCLE37完整修订：为上游控制器增加显式require_enabled_action_feedback选项，奶妹嵌入控制器固定启用。未接管时保留观察和候选计算，禁止把未执行的动作累计为拾取、火焰、移动或门口尝试失败；切换接管权限时仅清理进行中的计时、反馈基线，不清除真实已发生的失败与路线约束。真正启用输入后，无进展目标仍按原预算判失败。独立上游默认行为保持兼容，嵌入用法文档明确应启用该选项。

添加长时间未接管包、重新准入计时和真实启用无进展的回归，以及实际FairController与策略服务的完整包回归。全轮完成审阅提交后冻结统一测试。冻结后不再改代码。部署只更换本任务应用组件，保留同一活游戏、官方推流、声音、口型；不发送暂停、不杀游戏、不修改血量/道具/存档。实际恢复以新的模型决策、动作结果、口播和游戏状态为准，阶段继续running_candidate_not_accepted。

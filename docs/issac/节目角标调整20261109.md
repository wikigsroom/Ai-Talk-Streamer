# 节目角标调整（2026-11-09）

根据用户最新明确要求，issac 节目页面左上角主文字精确显示 `?!播播!?`，使用半角问号与感叹号。左上角 `.mc-brand`、右上角 `.mc-topic` 共用淡黄色背景：`rgb(255 246 204 / .93)`（#FFF6CC，93%不透明度）。

本轮只核验角标显示、持久配置与实际节目页面。已有音色、三种形态口型的用户审看结论继续适用于未改动的素材，不重复进行长时游戏录制或声明新增全面验收通过。

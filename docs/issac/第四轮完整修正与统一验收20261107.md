## 3．为什么要修正原生配置目录

依据：[Electron app.getPath](https://www.electronjs.org/docs/latest/api/app#appgetpathname) 说明 appData 与用户数据路径、失败时抛错；[Chromium Windows 路径实现](https://github.com/chromium/chromium/blob/main/base/base_paths_win.cc) 使用 SHGetFolderPath 解析 Windows 数据目录。修正是基于本机错误和该实现的判断，最终仍需本机启动证明。
